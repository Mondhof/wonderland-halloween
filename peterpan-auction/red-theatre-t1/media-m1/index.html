03 / HOW TO USE

照片、视频各三步

视频：1080P横版或竖版

  1. 在剪辑软件里打开1920×1080横视频或1080×1920竖视频。
  2. 将对应透明PNG加到最上层／画中画，四边与视频画布对齐，图层不透明度100%。
  3. 拉长PNG时长覆盖全片，检查Logo、人物、字幕和右侧按钮，再导出。

照片：按原片横竖尺寸

  1. 打开照片，选相同比例的横／竖透明PNG；本轮原片尺寸另有专用稿。
  2. 在图片编辑软件添加PNG图层，等比适配到照片四边，保留照片原分辨率。
  3. 查看两个角是否清晰且避开人物，再另存带水印照片；原照片保留。

水印不印在封面上重复叠放；封面已经有Logo和主题。画面明暗不均或人物挡住角标时，使用下面独立角标分别移动，不要拉伸Logo。视频竖版的主题已上提内缩，导出前仍需检查实际字幕与平台预览。

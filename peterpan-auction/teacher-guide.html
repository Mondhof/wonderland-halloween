人生拍卖会｜逐页授课与点击流程

HTML v1.3 · 33页 · 90分钟。与完整本地课件同源。先看学生动作，再按点击顺序教学；正式拍品和规则另确认。

第1页 · 让坚持， 成为底气

红版 / 蓝版

0—3分钟 / 本页3分钟

学生动作

找到你的号码牌。先看，不急着举。

点击顺序

观察舞台道具；找到号码牌；说出一个看到的物品。

教师示范与组织

签到时把号码与座位对应。让孩子先观察桌上道具，与家长就座。今天以表达和选择为目标，不用拍中数量评价孩子。 签到后发放并当面清点本人的实体积分币，具体数量依本场确认规则；号码牌与孩子一一对应。

回应与纠错

孩子能找到号码、说出一个看到的物件即可。

下一句转场

今天，要把决定交给你。

第2页 · 今天，你来做决定

红版 / 蓝版

3—5分钟 / 本页2分钟

学生动作

跟同伴说：今天我想练习……

点击顺序

依次点开说、听、决定；每一步请一位孩子用动作演示。

教师示范与组织

先给15秒思考，再两人各说20秒。接受一个词，邀请补成一句。请两名孩子回应即可，避免24人轮流上台占满时间。

回应与纠错

不以声音大、出价高作为本领强的证据。

下一句转场

先给家长一个小任务。

第3页 · 爸妈，先听我说

红版 / 蓝版

5—6分钟 / 本页1分钟

学生动作

孩子说完后，再问：你为什么这样想？

点击顺序

依次点先等待、记原话、问一个；家长先试着安静等三秒。

教师示范与组织

请家长用观察卡记原话。无人陪同的孩子由协助老师记录。家长代答时说“我们先听孩子说完，稍后请您问一个问题”。

回应与纠错

记录真实表达，不写统一的“表现特别棒”。

下一句转场

如果三个东西都喜欢，怎样选？

第4页 · 都喜欢，就都要吗？

红版 / 蓝版

6—7分钟 / 本页1分钟

学生动作

先别替小潘选。你还想知道什么？

点击顺序

切换物品，先猜再点“看看小潘怎么想”；每次切换重新隐藏想法。

教师示范与组织

这是虚构练习情境，物品不是正式拍品。由老师分别读出三句想法，只让孩子补“还想知道什么”，不先讲大道理。

回应与纠错

孩子可以问玩法、用途、自己已有物品；没有唯一答案。

下一句转场

替小潘作第一次选择。

第5页 · 先选哪一步？

红版 / 蓝版

7—9分钟 / 本页2分钟

学生动作

点一个考虑，再说出你的理由。

点击顺序

学生先选并说明；老师再点反馈；返回后换一种考虑。

教师示范与组织

允许学生举手表达，由老师点按钮。先听原因再打开反馈；选“马上举”也不嘲笑，追问是否了解物品。

回应与纠错

判断的是考虑有没有说清楚，不把个人偏好打成对错。

下一句转场

认识让选择顺利进行的工具。

第6页 · 号码不是金额

红版 / 蓝版

9—10分钟 / 本页1分钟

学生动作

请说：我是08号，我准备出……积分币。

点击顺序

看08号码牌和30报价；点选谁是编号，再说一次完整报价。

教师示范与组织

把实物号码牌举到主持人看得见的位置，不挡同伴。让两名孩子示范“号码”和“金额”，不要求每次报价都长篇说理由。

回应与纠错

别人应能听清编号和价格。牌上08不是8元。

下一句转场

接下来先做观察员。

第7页 · 三件物品，三种用途

红版 / 蓝版

10—11分钟 / 本页1分钟

学生动作

你准备把哪一件介绍给别人？

点击顺序

点击一个物品看用途；返回三物；说一个自己的使用场景。

教师示范与组织

现场有实物时优先拿出实物；目前课件使用清楚标注的类别示意。先不公布参考理由，避免孩子照搬老师答案。

回应与纠错

只需选一个练习对象，不是提前锁定竞拍资格。

下一句转场

看得具体，才能说得具体。

第8页 · 先看见，再下结论

红版 / 蓝版

11—14分钟 / 本页3分钟

学生动作

点开一个问题，补上你看到的细节。

点击顺序

按名字、特点、用途点击；先指物再说，随后揭示支架；可重新观察。

教师示范与组织

按“名字—特点—用途”逐次点开问题。孩子先指认再说，老师一次只追问一个细节；无法验证的功能说“我们还要核实”。

回应与纠错

把“很厉害”接成“哪一个地方让你这样想？”

下一句转场

把看见的细节，接到自己的理由后面。

第9页 · 把“因为”后面写完整

红版 / 蓝版

14—18分钟 / 本页4分钟

学生动作

你可以口头说，也可以把一句理由记在这里。

点击顺序

输入或口头说理由；点时间、动作、需要提示；最后用自己的细节再说一次。

教师示范与组织

老师或孩子录入一句练习表达；工具只给追问，不作AI评分。低龄先指物、说名，再由老师问“你想怎样用它”。

回应与纠错

没有自动对错分；教师根据现场回答选择一个追问。

下一句转场

给同伴听，再说第二次。

第10页 · 两个人，都有麦克风时间

红版 / 蓝版

18—22分钟 / 本页4分钟

学生动作

30秒说理由，30秒复述，再交换。

点击顺序

A说30秒，B复述30秒；计时可暂停；手动交换角色，再做一轮。

教师示范与组织

按座位两人配对。计时只提醒不判输赢，不自动换页；必要时暂停。老师先照顾安静孩子，给句首，不代答。

回应与纠错

每人至少一次表达和一次倾听；只记录观察到的表现。

下一句转场

小潘听过大家的理由，想法变了。

第11页 · 改变主意，也可以有理由

红版 / 蓝版

22—23分钟 / 本页1分钟

学生动作

你认为小潘改变了什么？什么没有变？

点击顺序

先说原来为什么选；点开现在的新信息；解释改变或维持的理由。

教师示范与组织

这段故事延续同一人物和物件。不评价“买本子就比买彩铅好”，引导孩子说信息如何影响决定。

回应与纠错

选择变了，仍需说清自己的理由。保持原决定也可以。

下一句转场

把自己的计划先记下来。

第12页 · 预算，是提醒自己的计划

红版 / 蓝版

23—25分钟 / 本页2分钟

学生动作

如果还有余额，你就必须继续吗？

点击顺序

拖动个人上限；先预计35报价是否超过计划，再点核对；重置可回30。

教师示范与组织

先问再揭示。孩子个人愿付上限可以低于规则封顶；不把预算解释成必须花完的金额。

回应与纠错

足够支付并不代表必须购买，个人计划可以不同。

下一句转场

正式成交后，要马上支付自己的积分币。

第13页 · 成交后，马上支付积分币

红版 / 蓝版

25—28分钟 / 本页3分钟

学生动作

请用练习币走一遍：点清 → 付款 → 核对。

点击顺序

从100积分的练习币里选出35再确认；少付或多付保留选择并给差额；准确付款后核对剩65；可重试。

教师示范与组织

先展示实体积分币与号码牌。孩子领取后清点；成交后由本人按成交价立即支付，登记老师当面点收，双方确认剩余币并登记后领取。用100积分、成交35积分示范，数出65积分；数字只是算例，不替代本场实际币数。此页练习不收正式积分币。

回应与纠错

核对的是实付数量、成交价和剩余币是否一致。发现不一致先暂停、当面复点；不让孩子承担登记错误。

下一句转场

下一题，手里的积分币不够怎么办？

第14页 · 20，能报25吗？

红版 / 蓝版

28—30分钟 / 本页2分钟

学生动作

选择一个动作，再说明原因。

点击顺序

对照20余额与25报价；选一项，再看差额5和追问；重试允许修正。

教师示范与组织

这题有数值限制。点“继续”需解释差额5并提供重试；停止和核对都可成立。不同于个人偏好题。

回应与纠错

先查清20与25；不能借别人的币，也不能让家长补钱。

下一句转场

如果余额够，还能停吗？

第15页 · 够支付，也能说“停”

红版 / 蓝版

30—32分钟 / 本页2分钟

学生动作

这里没有唯一的个人选择。关键是理由。

点击顺序

同时看40余额、30报价、25原计划；停或继续都需自己的理由。

教师示范与组织

先给5秒静想，点选只展示追问，不出现勾叉排名。若改变预算，必须仍在余额和本场上限内。

回应与纠错

继续要有新考虑；停止同样成立；问清信息也是一步。

下一句转场

写下你的个人计划。

第16页 · 我的选择卡

红版 / 蓝版

32—35分钟 / 本页3分钟

学生动作

先填卡，再跟同伴解释一次。

点击顺序

填写选择、理由、上限；点核对；输入仅保留本机，不录真实积分。

教师示范与组织

用现有选择卡，不新增同用途物料。不会写字的孩子口述，由协助老师记录；家长不替选。屏幕输入是示例，不收集孩子姓名。

回应与纠错

上限低于或等于本场上限及余额；选择可以后来改变，但要说明原因。

下一句转场

把个人计划放进统一规则里。

第17页 · 先把规则说清楚

红版 / 蓝版

35—37分钟 / 本页2分钟

学生动作

请用自己的话，说出一条规则。

点击顺序

看规则大数；再揭示成交后当场支付；完整资格与同价规则由老师读备注。

教师示范与组织

正式活动用孩子本人已领取的实体积分币，成交后立即支付；试拍不收正式积分币。100初始/10起拍/每次＋5/单份50封顶/一人最多一份均为本版演示值，现场须由负责人确认后统一宣布。原课堂积分的兑换或保留方式另行明确。

回应与纠错

不以关注转发、续费金额或家长代答增加竞拍优势。

下一句转场

把举牌的话说完整。

第18页 · 替主持人修一句话

红版 / 蓝版

37—39分钟 / 本页2分钟

学生动作

每找到一个缺项，就点开一张提示。

点击顺序

先听抢喊原句；逐次补号码、报价、等待确认；重置后让孩子自己说。

教师示范与组织

老师先故意说一次模糊报价，孩子指出缺项再点。不要一次把答案全显示。理由放在表达时段，不要求每次加价都讲长稿。

回应与纠错

可修成“我是08号，我出30积分币”。

下一句转场

你来报一次，主持人复述一次。

第19页 · 牌号＋报价，让别人听清

红版 / 蓝版

39—41分钟 / 本页2分钟

学生动作

练习号牌和金额，再请同伴复述确认。

点击顺序

修改练习号码和报价；先说再点主持人复述；非法范围可修正重试。

教师示范与组织

08是编号。让两人分别扮竞拍者和主持人，主持人复述“08号，30积分币，对吗？”这里不记真实成交。

回应与纠错

清晰比喊得大声更重要；听不清可以重报。

下一句转场

把一轮竞拍排成正确顺序。

第20页 · 先做哪一步？

红版 / 蓝版

41—43分钟 / 本页2分钟

学生动作

排完点“核对”；错了可以重排。

点击顺序

点步骤排到四格跑道；核对后用动作走一遍；清空可重排。

教师示范与组织

核对余额与资格必须发生在落槌前；落槌后本人立即支付，登记老师点收、确认剩余币，完成登记再领取。四步中的末步包含付款与登记，不等到最后统一收费。

回应与纠错

介绍 → 报价 → 核对 → 落槌、付款、登记领取。

下一句转场

试拍时，也可能有人停下来。

第21页 · “我不拍了”，怎样接？

红版 / 蓝版

43—44分钟 / 本页1分钟

学生动作

你想怎样回应同伴？

点击顺序

先读同伴原话；讨论怎样回应；点反馈后可返回改说法。

教师示范与组织

先问孩子为什么这样选再点反馈。对不愿公开解释的孩子接受停止，课后单独支持，不逼问家庭经济或私事。

回应与纠错

不把继续加价当勇敢，不把停下当失败。

下一句转场

遇到同价，也要按规则处理。

第22页 · 同价时，不比谁嗓门大

红版 / 蓝版

44—45分钟 / 本页1分钟

学生动作

如果没中签，你还有哪些参与办法？

点击顺序

依次看核对有效报价、封顶仍同价、按已公布办法处理；不现场临时改规则。

教师示范与组织

这套为建议规则。正式前明确点名与公开抽签办法、能否撤回等，同场不能临时改变。抽签不按谁说得最好决定，避免让弱基础孩子吃亏。

回应与纠错

未竞得者保留币，可继续后续类别；已竞得者改做介绍或提问。

下一句转场

先演练一轮，不扣真实积分。

第23页 · 试拍一次，练会再开始

红版 / 蓝版

45—50分钟 / 本页5分钟

学生动作

主持人，请复述报价，再核对。

点击顺序

先报清编号与价格，手动推进三句主持口令；点核对，听本人确认，再点模拟付款并记录。重复/超额/份数等限制会拦截；可撤销本类上一笔。

教师示范与组织

模拟账本与正式积分完全分开。最多24个编号，重复竞得/余额不足/超过50时应被拦截。主讲控制确认，不自动落槌。试拍结束可在教师设置清空演示记录。 试拍也走一次“付款—点清—登记领取”的动作，用练习币或口头模拟，不收孩子正式积分币。

回应与纠错

有错误先停下、说明、再试一次，不扣惩罚币。

下一句转场

现在喝口水，再把表达带入竞拍。

第24页 · 喝口水，看看自己的计划

红版 / 蓝版

50—54分钟 / 本页4分钟

学生动作

休息结束，再决定下一步。

点击顺序

启动休息计时；看看自己的选择卡；需要帮助时先暂停，不自动翻页。

教师示范与组织

四分钟含饮水、回座与核对。计时器只提示不自动跳页或落槌，孩子需要时暂停。教师检查台账，不趁休息加讲新概念。

回应与纠错

安静或情绪紧张的孩子可以稍作调节，不用新奖品诱导继续。

下一句转场

第一类拍品，先听介绍。

第25页 · 拍卖示例｜把故事讲出来

红版 / 蓝版

54—69分钟 / 本页15分钟

学生动作

介绍员先说用途，其他人听完再举牌。

点击顺序

先报清编号与价格，手动推进三句主持口令；点核对，听本人确认，再点模拟付款并记录。重复/超额/份数等限制会拦截；可撤销本类上一笔。

教师示范与组织

只保留这一组示例，不重复展开三类拍品。15分钟建议：2分钟介绍和提问，10分钟按本场已确认拍品逐件短拍并立即支付，3分钟由未参与报价的孩子轮换介绍、提问和说明选择；实际件数以现场清单为准，不以示例4份代替采购确认。落槌后本人按成交价立即支付实体积分币，登记老师当面点收、确认余额后领取。网页仅演示，不代收或保管真实积分币。
主持人备忘（原30页，学生屏幕不展示）：主讲可补一条准确用途或回答一个问题，但不夸大价值、不临时修改奖励规则。未成交物品按负责人预先确认办法处理。 冷场时允许继续观察，不催抢、不强迫成交。

回应与纠错

避免所有时间只听活跃孩子；未竞价者可做提问者。

下一句转场

每笔当场付款，再共同核对记录。

第26页 · 付完积分币，再核对记录

红版 / 蓝版

69—71分钟 / 本页2分钟

学生动作

每笔成交当场支付；有出入，先暂停领取、一起复点。

点击顺序

先看模拟账本；按号码、成交实付、剩余币逐项核对；无记录时只演示流程。

教师示范与组织

本页演示账本不替代正式登记。每笔成交立即收取实体积分币，当面点收、登记，双方确认后领取；本页用于再次复核，不是到最后才付款。正式台账记号码、品名、成交价、实付数量、剩余币和收付双方确认。发生错误先查原记录，不能让孩子承担老师记错的损失。

回应与纠错

100−35＝65仍是算例。正式收付按孩子实有积分币和现场成交记录核对。

下一句转场

东西可以不同，理由都值得听。

第27页 · 先复述，再提问

红版 / 蓝版

71—73分钟 / 本页2分钟

学生动作

先等同伴确认，再问你的问题。

点击顺序

先听原话，点开始复述；手动等对方回应，再进入说者确认、相关追问；可收起重来。

教师示范与组织

同伴先说20—30秒，倾听者复述一个意思。说话者可纠正，确认后再点开提问示例。不要把教师复述替代孩子倾听。

回应与纠错

提问跟对方理由有关，不考倒对方。

下一句转场

哪一个问题，能帮助你听明白？

第28页 · 好问题，接着对方的话

红版 / 蓝版

73—75分钟 / 本页2分钟

学生动作

选一个问题，再试着问出来。

点击顺序

读同伴原话再选追问；先口头讨论再揭示反馈；返回重试。

教师示范与组织

先让同伴讨论，老师点击反馈。围绕用途与个人计划继续，而不是把“贵”或“赢”设成唯一价值。

回应与纠错

问题是否相关可讨论，不给孩子贴会/不会听的标签。

下一句转场

把“说—听—问—答”走完整。

第29页 · 交换一次，听见两个人

红版 / 蓝版

75—80分钟 / 本页5分钟

学生动作

每人都完成一次说、听、问、答。

点击顺序

A说、B复述、A确认、B问、A答；90秒提醒；手动交换角色再完成一轮。

教师示范与组织

给每组完整轮换，不只请代表上台。教师巡视记一句真实原话，基础弱孩子可先用一个词或指物，不连续追问三四次。

回应与纠错

老师一次给一个建议，例如“先复述用途，再问什么时候使用”。

下一句转场

回头看看，最初的计划还一样吗？

第30页 · 我的选择，前后有什么不同？

红版 / 蓝版

80—83分钟 / 本页3分钟

学生动作

对家长或同伴，解释一个真实决定。

点击顺序

对照先前选择和现在决定；写一个真实理由；维持原计划也成立。

教师示范与组织

拿出课前选择卡，与现在对照。没有拍中也能讲停止或观察的理由；不把所有变化都写成进步。家长先听再复述。

回应与纠错

只记事实：孩子补了什么信息、怎样解释、怎样回应。

下一句转场

把一个具体进步说给孩子听。

第31页 · 今天，我听见了什么？

红版 / 蓝版

83—85分钟 / 本页2分钟

学生动作

请选择一个你确实观察到的表现。

点击顺序

先说观察到的原话；逐步展开具体表现与一个下一步建议；不评价输赢。

教师示范与组织

教师按钮展示的是反馈句框，不是自动判定。没有观察证据就不套用；公开只选少量例子，其他孩子用反馈卡补齐。

回应与纠错

反馈落到用途、理由、复述或决定，不统一写“都很棒”。

下一句转场

把这个动作带回家。

第32页 · 回家，再做一次自己的选择

红版 / 蓝版

85—88分钟 / 本页3分钟

学生动作

家长只问一个问题，把回答留给孩子。

点击顺序

切换三档任务；按能力选一档；录制前先说一遍，不照背方法示例。

教师示范与组织

三档按实际表达能力选，不按红蓝风格分层。提交方式/截止/反馈时间由当班老师填写；不要求公开发布视频。示例台词可看，但不能逐字照背。

回应与纠错

允许停顿与口头补交，是否可补交按本班实际安排。

下一句转场

最后，把选择与声音带走。

第33页 · 有声， 有主见

红版 / 蓝版

88—90分钟 / 本页2分钟

学生动作

把一句自己的理由，留在今天。

点击顺序

请孩子补一句今天自己的决定；回应具体理由；不按竞得数量评表现。

教师示范与组织

收回工具，确认领取与离场安排。合影自愿且按既有影像权限，不只展示竞得者；安排下一步家长反馈，不现场承诺长期能力变化。

回应与纠错

尊重每个孩子不同的决定。

下一句转场

课程结束，保留观察，继续练习。

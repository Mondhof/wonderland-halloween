# 活动影像封面与水印默认规范
2026-10-23 刘玥本人明确要求；以后每次活动随课件、宣传及物料同步交付。

1. 三平台封面：视频号、抖音、小红书分别组织版式，标实际像素与用途；上传画布、主页/分享裁切区分开。平台规则需核实，不把旧数值当永久强制标准；需要时补适配版。朋友圈仍按既定1:2，不能由此改成平台封面比例。
2. 视频水印：至少1920×1080横版、1080×1920竖版；PNG完整透明画布，放剪辑顶层/画中画贯穿全片。原品牌Logo在左上、当次课程/活动主题在右下；留字幕/播放器按钮空间，发布前实际检查。
3. 照片水印：常见相机3:2横版、2:3竖版，高像素；按本轮相机原片实测尺寸提供对应稿。常用手机4:3、3:4可补配。不能把横照强拉成竖照或固定套错比例。水印图层匹配画布，原照片不必降至视频1080P。
4. 完整原品牌标识按对应品牌调用，彼得潘/温德兰不混；不拆分、不重绘。温德兰默认Power Support logo水印_Logo透明.png的完整CAMBRIDGE+Power Support组合。普通字体不可冒充Logo。图层100%不透明，复杂背景可用轻微柔光提高可见性，不用大底栏盖住人物。
5. 交付可直接用的封面JPG/PNG、透明叠加PNG、品牌/主题独立原件、尺寸/位置表、最简操作说明、效果示意和分类下载/ZIP；示意图与透明叠加素材分开。PNG中央须真实透明，不能带棋盘底或整页白底。
6. 先实际看参考，保存模板规范、本次指导，代表样张检验后延展。分别验收尺寸、比例、透明区、角落位置、文案、品牌原图、主体和裁切避让、实际下载。素材导出成功不等于已在平台发布或已逐设备裁切验收。
7. 参考照片按其品牌与用途使用；不同品牌或其它活动照片不冒称本次活动实拍。公开不需要的人像原件不入公共下载包。此规则不扩大公开、社交发布、发群或肖像使用权限；仍按本轮真实授权范围。

本次万圣节额外工作口径：视频号9:16主版+6:7备用；抖音9:16主版+3:4主页；小红书3:4。8张透明模板含1080P横竖视频、相机通用及所给原尺寸横竖照片、手机常用横竖照片。这是本次制作规格，不是各平台唯一强制尺寸。
